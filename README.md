# Olive & Thyme – Restaurant Website

A simple HTML5 restaurant website made for **UYG211 Internet Programming I – Homework 1**.

## Pages
- `index.html` – Home page
- `menu.html` – Food menu (table) and drinks (list)
- `about.html` – Our story, opening hours and contact
- `reservation.html` – Table reservation form

## How to run
**Live site:** https://bekirbm.github.io/restaurant-website/

Or download the repository and open `index.html` in a web browser (e.g. Google Chrome).
